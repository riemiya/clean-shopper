# Clean Shopper — Phase 1 Scope

## What we're building

A clean product directory with ingredient transparency.

## 5 tickets

| # | Task | Priority |
|---|------|----------|
| CS-004 | Session management | P1 |
| CS-001 | App structure and routing | P1 |
| CS-009 | Product recommendation cards | P1 |
| CS-014 | Dietary tag chips and filters | P2 |
| CS-010 | Ingredient safety display (product detail page) | P1 |

## What users can do at the end of phase 1

- Browse and search for products with name, brand, and clean score
- Filter products by dietary tags (vegan, gluten-free, non-GMO, etc.)
- Tap a product to see the full ingredient list with safety ratings and reasoning
- Return later with their session intact — nothing resets between visits
